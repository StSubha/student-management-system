# 📘 Student Record System

A fully-featured GUI-based Student Record System built using **Python**, **PyQt5**, and **SQLite**. This desktop application helps manage student data with a clean, modern interface. It supports adding, updating, deleting, searching records, Excel export, and more.

---

## 🚀 Features

- 🧾 Add / Edit / Delete student records
- 🔍 Instant Search with Filter
- 📤 Export to Excel (.xlsx)
- 🖥️ Modern PyQt5 Interface
- 💾 SQLite Database Integration
- 🪟 Resizable Window with Custom Icon
- 📋 Copy/Paste Number Functionality
- 🧠 Scientific Functions in Calculator (ln, x², ×10ˣ)
- ⚙️ Compilable to Windows `.exe` using PyInstaller

---

## 🛠️ Tech Stack

- **Language:** Python 3.x
- **GUI:** PyQt5
- **Database:** SQLite
- **Excel Export:** `pandas`, `openpyxl`
- **EXE Packaging:** PyInstaller
